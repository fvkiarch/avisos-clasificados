# avisos-clasificados
Proyecto para Bases de Datos &amp; Programación PHP

Modo de uso:

Renombrar .env.example a .env

Generé scripts tanto para Linux como para Windows (serve.bat y serve.sh).

La idea es que una vez que esté levantado xampp, se ejecute el script de acuerdo al sistema operativo.

El mismo script debería crear la base y ejecutar los archivos sql dentro de la misma.

En caso de que no funcione o haya problemas habría que entrar a phpmyadmin y ejecutar los scripts 01, 02, 05, 06 manualmente.
